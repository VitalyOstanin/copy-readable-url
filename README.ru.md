# Copy Readable URL

[English](README.md) | Русский

Расширение для браузеров на Chromium (Chrome, Brave, Edge). Копирует адреса с кириллицей и другими не-ASCII символами в читаемом виде, а не в процентной кодировке (`%D0%9C%D0%BE...`), которую адресная строка кладёт в буфер обмена. Также может скопировать адрес готовой markdown-ссылкой.

```
https://ru.wikipedia.org/wiki/%D0%9C%D0%BE%D1%81%D0%BA%D0%B2%D0%B0
→ https://ru.wikipedia.org/wiki/Москва
→ [Москва](https://ru.wikipedia.org/wiki/Москва)
```

## Назначение

Когда адрес копируется целиком, адресная строка Chromium кладёт в буфер канонический URL, в котором каждый не-ASCII символ закодирован (`AdjustTextForCopy` в [`components/omnibox/browser/omnibox_text_util.cc`](https://chromium.googlesource.com/chromium/src/+/refs/heads/main/components/omnibox/browser/omnibox_text_util.cc)). Настройки, отключающей это, нет. В Firefox она есть: `browser.urlbar.decodeURLsOnCopy` в `about:config`.

## Использование

| №   | Действие                                                        | Что копируется                          |
|-----|-----------------------------------------------------------------|-----------------------------------------|
| 1   | `Alt+U`                                                         | адрес текущей вкладки                   |
| 2   | `Alt+Shift+U`                                                   | адрес текущей вкладки markdown-ссылкой  |
| 3   | Контекстное меню ссылки → «Копировать ссылку»                   | адрес ссылки                            |
| 4   | Контекстное меню ссылки → «Копировать ссылку как markdown»      | адрес ссылки markdown-ссылкой           |
| 5   | Контекстное меню страницы → «Копировать адрес страницы»         | адрес страницы                          |
| 6   | Контекстное меню страницы → «Копировать адрес страницы как markdown» | адрес страницы markdown-ссылкой    |

После каждого копирования на значке расширения на 1,5 секунды появляется `OK` или `ERR`. Пункты меню и названия команд следуют языку браузера (русский или английский).

Markdown-ссылка имеет вид `[заголовок](адрес)`. Заголовок — последняя непустая часть пути, раскодированная полностью (`%20` становится пробелом), либо имя хоста, если путь пустой.

## Установка

Расширения пока нет в Chrome Web Store, оно ставится как распакованное.

1. Скачайте код: `git clone https://github.com/VitalyOstanin/copy-readable-url.git` или ZIP со страницы GitHub, распакуйте.
2. Откройте `chrome://extensions` (в Brave — `brave://extensions`, в Edge — `edge://extensions`) и включите «Режим разработчика» (*Developer mode*).
3. Нажмите «Загрузить распакованное расширение» (*Load unpacked*) и выберите каталог проекта, в котором лежит `manifest.json`.
4. Проверьте, что оба сочетания назначены, см. [Сочетания клавиш](#сочетания-клавиш).

Обновление: `git pull` (или распаковать новый ZIP в тот же каталог) и кнопка обновления на карточке расширения. Каталог не удаляйте: браузер загружает расширение из него при каждом запуске.

## Сочетания клавиш

Расширение предлагает `Alt+U` (скопировать адрес страницы) и `Alt+Shift+U` (скопировать адрес страницы как markdown-ссылку). Браузер назначает предложенное сочетание, только если его не использует другое расширение; иначе команда остаётся без сочетания, и нажатие клавиш ничего не делает.

Как проверить или изменить сочетания:

1. Откройте страницу сочетаний:
   - Chrome: `chrome://extensions/shortcuts`;
   - Edge: `edge://extensions/shortcuts`;
   - Brave: откройте `brave://extensions` и выберите *Keyboard shortcuts* в левой панели.
2. Найдите *Copy Readable URL*. У него две команды: «Копировать адрес страницы» и «Копировать адрес страницы как markdown-ссылку» (при английском интерфейсе — *Copy page URL* и *Copy page URL as markdown link*).
3. Нажмите кнопку редактирования (или пустое поле) рядом с командой и нажмите новое сочетание. Сочетание должно включать `Ctrl` или `Alt`; на macOS `Alt` — это клавиша `Option`, а `Ctrl` заменяется на `Command`.
4. Если сочетание уже занято другим расширением, выберите другое или сначала снимите его у того расширения (на этой же странице), затем назначьте здесь.
5. Область действия оставьте прежней — только в браузере (*In Chrome*, *In Brave*, *In Edge*), не глобальной (*Global*): расширению нужна активная вкладка окна браузера, находящегося в фокусе.

Пункты контекстного меню от сочетаний не зависят и работают всегда.

## Что раскодируется

- **Путь, параметры запроса, фрагмент.** Закодированные UTF-8 последовательности не-ASCII символов раскодируются по одному символу. ASCII-коды (`%20`, `%2F`, `%3F`, `%26`) остаются закодированными, чтобы адрес сохранял смысл и оставался корректной целью markdown-ссылки. Некорректный UTF-8 (например, запрос в cp1251) остаётся как есть.
- **Невидимые символы остаются закодированными:** пробелы, управляющие символы и символы смены направления текста (`%C2%A0`, `%E2%80%8B`, `%E2%80%AE`), чтобы раскодированный адрес нельзя было выдать за другой.
- **Кавычки-ёлочки и типографские кавычки остаются закодированными** (`«` `»` `“` `”` `…` и остальные знаки блока General Punctuation, кроме дефисов и тире): Telegram обрывает на них автоматически распознанную ссылку, и раскодированные `«...»` укорачивали бы вставленную ссылку.
- **Доменные имена** (`xn--...`, punycode) раскодируются по частям, если все буквы части относятся к одной письменности (латиница, кириллица, греческий, японский, корейский и другие) и раскодированная часть преобразуется обратно в ту же форму `xn--`. Части со смешением алфавитов (`аpple` с кириллической `а`) остаются в punycode. Вне кириллических доменов верхнего уровня в punycode остаются и части только из кириллических букв, похожих на латинские (`аррӏе.com`).
- **Заголовок markdown-ссылки:** экранируются `[`, `]`, `*`, `` ` ``, `<` и `\`; `_` не экранируется, так как подчёркивание внутри слова в CommonMark не означает выделение. Адрес с несбалансированными скобками заключается в `<...>`.

## Разрешения и приватность

| №   | Разрешение       | Для чего                                                                  |
|-----|------------------|---------------------------------------------------------------------------|
| 1   | `activeTab`      | чтение адреса текущей вкладки при нажатии сочетания клавиш               |
| 2   | `contextMenus`   | четыре пункта контекстного меню                                           |
| 3   | `offscreen`      | скрытая страница, которая пишет в буфер обмена (service worker этого не может) |
| 4   | `clipboardWrite` | запись раскодированного адреса в буфер обмена                             |

Расширение не делает сетевых запросов, ничего не хранит и читает только тот адрес, который вы просите скопировать.

## Разработка

Сборки нет: расширение состоит из обычных JavaScript-модулей, которые загружаются как есть. Для тестов нужен Node.js 20 или новее:

```
npm test
```
